# D'Écuyer à Chevalier

Jeu d'aventure médiévale en 3D, jouable directement dans le navigateur.

**▶ Jouer : https://godsaucisse.github.io/ecuyertochevalier/**

Anno Domini 1126. Tu es un jeune écuyer arrivé au château de Montclair. Sers ton seigneur,
entraîne-toi au maniement des armes et gagne le droit d'être adoubé chevalier.

## Commandes
- **Z Q S D** ou flèches : se déplacer · **Maj** : courir · **Espace** : sauter
- **Souris** : regarder · **Molette** : zoom
- **E** : parler · **Clic gauche** ou **F** : frapper
- Sur mobile : joystick à gauche, glisser à droite pour la caméra, boutons d'action.

Construit avec [Three.js](https://threejs.org) (licence MIT, voir `lib/LICENSE-three.txt`).
